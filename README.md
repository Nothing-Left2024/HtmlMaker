# HtmlMaker

[中文](./README.md) | [English](./README_EN.md)

可视化 HTML / CSS / JavaScript 积木编辑器。通过拖拽、组合积木块，无需编写代码即可创建完整的网页。

作者：Clean　版本：1.1

---

## 项目简介

HtmlMaker 将网页开发拆解为三种积木：HTML 标签积木、CSS 样式积木、JavaScript 语句积木。用户在三个独立页面中拖拽积木、组合嵌套，即可生成可运行的网页代码。适合编程教学、快速原型搭建和无代码网页创作。

## 功能特性

### 三页编辑架构

- HTML 页：搭建页面结构，支持容器、文本、媒体、表单、列表、表格等标签
- CSS 页：编写样式规则，选择器作为起点，样式属性积木拖入选择器内
- JS 页：添加交互逻辑，事件作为顶级起点，控制流与语句可嵌套

### 积木编辑

- 拖拽添加：从左侧调色板拖拽积木到工作区
- 嵌套组合：容器积木可放入子积木，构建层级结构
- 内联参数：积木上直接显示输入框，实时编辑参数
- 兼容校验：不兼容的嵌套会自动提示并拒绝
- 拖回删除：将积木拖回左侧调色板即可删除
- 半透明预览：拖拽时在目标位置显示半透明预览

### 交互与导航

- 自定义右键菜单：替代浏览器默认菜单，提供复制、删除、编辑属性等操作
- 分类竖栏：最左侧竖栏按分类组织积木，点击图标快速跳转
- 搜索过滤：调色板顶部搜索框，按关键词查找积木
- 积木悬浮提示：鼠标悬停调色板积木显示说明

### 视图与导出

- 实时代码预览：右侧面板实时显示生成的 HTML / CSS / JS 代码
- 渲染预览：点击预览按钮切换到 iframe 渲染视图（已禁用跳转和重定向）
- 代码区可拖拽调整宽度，宽度自动持久化
- 导出完整 HTML / 仅 CSS / 仅 JS / 项目 JSON
- 导入 HTML 文件：自动解析标签、样式、脚本并转换为积木
- 导入项目 JSON：恢复之前导出的项目

### 用户体验

- 深色 / 浅色主题切换，平滑过渡
- 首次使用引导教程（12 步静态教程 + 4 步交互式实操）
- 子页面转场动画（iOS 风格横向滑动）
- 撤销 / 重做（Ctrl+Z / Ctrl+Y）
- 复制 / 粘贴 / 原地复制（Ctrl+C / Ctrl+V / Ctrl+D）
- 自动保存到 LocalStorage，刷新不丢失

## 快速开始

无需安装任何依赖，直接用浏览器打开即可：

1. 下载项目文件
2. 用现代浏览器（Chrome、Edge、Firefox、Safari）打开 `index.html`
3. 首次打开会显示引导教程，可按步骤学习或点击跳过

## 使用指南

### 基本操作

| 操作 | 方式 |
|------|------|
| 添加积木 | 从左侧调色板拖拽到工作区 |
| 嵌套积木 | 拖拽到某个积木内部 |
| 插入积木 | 拖拽到两个积木之间 |
| 删除积木 | 拖回左侧调色板，或右键菜单选择删除 |
| 编辑参数 | 点击积木上的输入框直接编辑 |
| 编辑属性 | 右键积木，在菜单中编辑标签属性或样式 |

### 积木分类

HTML 页：

- 容器：div、section、article、header、footer、nav、main 等
- 文本：p、span、h1-h3、a、strong、em、br 等
- 媒体：img、video、audio、iframe、source
- 表单：form、input、button、label、textarea、select 等
- 列表：ul、ol、li、dl、dt、dd
- 表格：table、tr、td、th、thead、tbody、caption

CSS 页：

- 起点：标签选择器、类选择器、ID 选择器
- 样式属性：宽高、颜色、背景、字号、边距、边框、圆角、显示、定位等

JS 页：

- 事件：页面加载、点击元素、输入
- 控制流：条件、循环、跳转、异常、分支
- 变量：声明、赋值
- 函数：定义、调用、返回
- DOM 操作：获取 / 设置文本、HTML、样式、类名、属性
- 输出：日志、弹窗、输入框、确认框
- 运算：加減乘除、取余、最大最小、取整、随机、绝对值
- 字符串：长度、大小写、截取、拼接、替换、分割、转换
- 数组：创建、增删、长度、读写、连接、排序、反转
- 对象：创建、读写、属性列表
- JSON：解析、序列化
- 类型转换：parseInt、parseFloat、toFixed、typeof
- 异步操作：Promise、await、fetch、定时器

### 导入与导出

点击右上角「文件」按钮打开导入 / 导出面板：

- 导出完整 HTML：包含 HTML 结构、CSS 样式、JS 脚本的独立 HTML 文件
- 导出仅 CSS：所有 CSS 规则
- 导出仅 JS：所有 JavaScript 语句
- 导出项目 JSON：项目完整数据，可用于备份和恢复
- 导入项目 JSON：从备份文件恢复项目
- 导入 HTML：上传 HTML 文件，自动解析标签结构、内联样式、style 标签、script 标签并转换为积木

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无构建工具、无外部依赖
- 数据存储于 LocalStorage，无需后端服务
- 积木采用 Scratch 风格拼图外观（顶部凸起 + 底部凹陷咬合）
- 主题配色使用 CSS 变量，深色 / 浅色模式平滑切换
- 子页面转场仅动画 transform 属性，GPU 合成保证流畅
- 预览 iframe 通过 sandbox 属性和注入脚本双层禁用跳转与重定向
- 导入 HTML 解析器基于 DOMParser 和正则匹配，支持常见标签、内联样式、style 标签、script 标签

## 设计原则

界面遵循「情感化极简」风格，参考 Apple 设计规范：

- 卡片式布局：柔和圆角、细腻阴影、清晰层次
- 双重阴影：内阴影顶部高光 + 外阴影底部投影，营造立体质感
- 悬停反馈：可交互元素悬停时微上浮并伴随阴影变化
- 克制配色：低饱和度柔和色调，深色模式提亮强调色
- 可访问性：键盘焦点指示、方向键导航、Escape 关闭
